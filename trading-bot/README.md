# 주식 백테스트 프로그램

과거 데이터로 매매 전략을 미리 시험해보는 도구입니다. **아직 실제 돈으로 거래하지 않습니다.**
지금은 "이 전략이 과거에 잘 통했는지" 확인하는 단계이고, 실전 자동매매는 다음 단계입니다.

국내(코스피/코스닥)와 미국 주식을 모두 지원합니다.

## 처음 실행하기

1. 파이썬 3.10 이상이 필요합니다. (`python3 --version` 으로 확인)
2. 폴더로 이동해서 필요한 패키지를 설치합니다.
   ```
   cd trading-bot
   pip install -r requirements.txt
   ```
3. 예시로 삼성전자를 백테스트해봅니다.
   ```
   python main.py --market kr --symbol 005930 --start 2020-01-01 --end 2024-01-01 --plot
   ```
   미국 주식(애플) 예시:
   ```
   python main.py --market us --symbol AAPL --start 2020-01-01 --plot
   ```

실행하면 이런 결과가 나옵니다.

```
종목: kr/005930  기간: 2020-01-02 ~ 2024-01-02
전략: MA(20/60)  초기자금: 10,000,000
--------------------------------------------------
최종 자산     : 12,345,678
총 수익률     : 23.46%
연평균 수익률 : 5.42%
최대 낙폭(MDD): -18.30%
샤프 비율     : 0.61
매매 횟수     : 14
승률          : 42.86%
```

`--plot`을 주면 `results/` 폴더에 자산 변화 그래프(png)가 저장됩니다.

## 전략 설명 (이동평균 교차)

- 최근 20일 평균 가격이 60일 평균 가격을 위로 뚫고 올라가면 **매수**
- 반대로 아래로 뚫고 내려가면 **매도**
- `--short`, `--long` 옵션으로 기간을 바꿔볼 수 있습니다. (예: `--short 5 --long 20`)

## 폴더 구조

| 폴더 | 역할 |
|---|---|
| `data/` | 시세 데이터를 가져오는 부분 (국내/해외) |
| `strategies/` | 매매 전략 (지금은 이동평균 교차 하나) |
| `backtest/` | 과거 데이터로 시뮬레이션하고 성과를 계산하는 엔진 |
| `broker/` | (비어있음) 나중에 실전 자동매매용 증권사 API를 연결할 자리 |
| `main.py` | 실행 진입점 |

## 새 전략을 추가하려면

`strategies/base.py`의 `Strategy`를 상속받아 `generate_signals()`만 구현하면 됩니다.
(RSI, 볼린저밴드 등도 같은 방식으로 추가 가능)

## 다음 단계: 실전 자동매매

백테스트로 전략이 쓸만하다고 판단되면, `broker/base.py` 인터페이스를 구현하는
증권사 어댑터(예: 한국투자증권 KIS API, 삼성증권 등)를 추가해서 실제 주문을 넣게 됩니다.
이 단계는 증권사 API 발급/인증이 필요하므로 별도로 진행합니다.

⚠️ 실전 자동매매는 실제 돈이 오가는 만큼, 반드시 모의투자(paper trading)로 충분히
검증한 뒤에 소액으로 시작하는 것을 권장합니다.
