# 나의 작은 카페 (모바일 방치형 카페 경영 게임)

손님을 받고, 다양한 음료·디저트를 팔아 돈을 벌고, 매장을 증축하고 직원을
고용해가며 키우는 모바일 웹 경영 시뮬레이션 게임입니다. 지금 있는 AI 오피스
프로젝트와는 완전히 별개의 프로젝트로, 이 `cafe-game/` 폴더 안에서만 동작해요.

## 폰으로 바로 실행하기 (설치 없이)

1. 이 저장소의 **Settings → Pages** 에서 Source를 **GitHub Actions** 로 한 번만
   설정해주세요. (레포가 비공개면 GitHub Pro/Team 이상이거나, 공개 레포여야
   Pages를 쓸 수 있어요.)
2. 이 브랜치에 커밋이 올라갈 때마다 `.github/workflows/cafe-game-pages.yml`
   워크플로가 자동으로 빌드해서 아래 주소에 올려줍니다:

   **https://smin7752-ops.github.io/-/**

3. 폰 브라우저로 그 주소를 열면 바로 플레이할 수 있어요. 크롬/사파리에서
   **"홈 화면에 추가"** 를 누르면 앱처럼 아이콘이 생기고, 인터넷이 잠깐 끊겨도
   실행됩니다 (PWA로 만들어져 있어요).

Pages를 아직 안 켰거나 우선 로컬에서 확인하고 싶다면 아래 "직접 실행하는 법"을
따라 하세요.

## 직접 실행하는 법 (컴퓨터에서)

```bash
cd cafe-game
npm install
npm run dev
```

터미널에 뜨는 주소(`http://localhost:5173`)를 브라우저로 열면 됩니다.
휴대폰으로 확인하려면 같은 와이파이에 연결한 뒤, PC의 IP 주소로 접속하세요
(터미널에 `Network:` 로 시작하는 주소가 같이 나옵니다).

## 어떻게 노는 게임인가요

- **영업 시간**: 매일 아침 10시에 열고 밤 10시(22시)에 마감해요. 마감 때
  하루치 인건비가 한 번에 정산되고, 다음 날 아침 10시에 다시 열립니다.
- 손님이 문으로 들어와 빈 테이블에 앉고(한 테이블에 2명), 원하는 메뉴를
  말풍선으로 보여줘요.
- **바리스타**가 없으면 손님을 눌러 직접 음료/디저트를 만들어야 하고,
  **홀 직원**이 없으면 직접 서빙하고 다 먹은 테이블도 직접 치워야 해요.
  둘 다 고용한 층은 자리를 비운 동안에도 알아서 돌아갑니다.
- 너무 오래 기다리게 하면 손님이 화를 내고 나가고, **가게 평점**이 떨어져요.
  평점이 높을수록 손님이 더 자주 옵니다.
- 메뉴는 팔 때마다 경험치가 쌓여 레벨이 오르고, 레벨이 오르면 판매가도
  올라요. 앞 메뉴를 일정 레벨까지 키우면 다음 메뉴(더 비싼 음료/디저트)가
  열립니다. 음료와 디저트를 하나씩 묶은 **세트 메뉴**도 있어서, 둘 다 팔 수
  있게 되면 손님이 가끔 세트로 주문해요.
- 화면 아래 탭에서 관리할 수 있는 것들:
  - **메뉴** — 음료/디저트 레벨과 다음 해금 조건 확인
  - **발주** — 메뉴별 재고 채우기 (재고가 없으면 그 메뉴로는 손님이 안 와요).
    **점장**을 고용하면 재고가 부족할 때 자동으로 발주해줘요
  - **직원** — 층마다 따로! 바리스타·홀 직원(각 최대 4명)과 매니저(손님을
    더 빨리 불러모음)를 고용/강화
  - **매장** — 층마다 테이블 추가, 새 층 증축 (최대 4개 층)
  - **설비** — 커피머신은 기본 제공, 쇼케이스/티 스테이션/블렌더/오븐은
    구매해서 해금
  - **매출표** — 오늘/지난 날의 매출·재료비·인건비·순이익 확인, 가게 평점
  - **유니폼** — 층 전체에 적용되는 장비. 입고 있을 때만 효과가 있는 것과,
    갖고만 있어도(모으기만 해도) 가게 전체에 붙는 효과가 따로 있어요
- 돈이 모자라도 영업은 계속돼요 — 마이너스(빚)여도 다음 날로 넘어갑니다.
- 진행 상황은 브라우저에 자동 저장됩니다(로그인 없이도 저장돼요). 자리를
  비운 동안에도 자동화된 층은 계속 돈을 벌고, 다시 들어오면 그동안 번 돈을
  몰아서 보여줘요.

## 나중에 앱스토어/플레이스토어에 정식으로 내고 싶다면

지금은 **모바일 웹 게임 + PWA**로 만들어져 있어서, 링크만 있으면 누구나 바로
플레이하거나 홈 화면에 설치할 수 있습니다. 나중에 진짜 앱스토어/플레이스토어에
올리고 싶어지면, 이 웹 프로젝트를 그대로 유지한 채
[Capacitor](https://capacitorjs.com)라는 도구로 감싸서 iOS/Android 앱으로
빌드할 수 있어요. 지금 짜여진 코드를 다시 만들 필요는 없습니다 — "이 게임을
앱스토어에 낼 준비를 해줘" 라고 말씀해주시면 그때 Capacitor 설정을 추가해
드릴게요.

## 폴더 구조

```
cafe-game/
  src/
    game/       게임 규칙 (config.ts 밸런스 값, sim.ts 시뮬레이션, state.ts 저장,
                art.ts 손그림 아이콘)
    scenes/     카페 화면 (Phaser 게임 엔진으로 그려지는 부분)
    ui/         상단 바, 탭, 상점류 창 (HTML/CSS로 그려지는 부분)
    main.ts     게임을 실제로 켜는 시작점
  public/       앱 아이콘, PWA manifest, 오프라인 캐시(sw.js)
  index.html
.github/workflows/cafe-game-pages.yml   GitHub Pages 자동 배포
```

## 손보고 싶을 때 어디를 고치면 되나요

- **메뉴 종류, 가격, 해금 조건, 세트 메뉴** → `src/game/config.ts`
- **테이블/직원/층/설비 가격, 영업시간, 인건비** → `src/game/config.ts`
- **손님 인내심, 평점 변화 규칙, 하루 정산 로직** → `src/game/sim.ts`,
  `src/game/state.ts`
- **카페 이름, 화면 문구** → `index.html`, `src/scenes/CafeScene.ts`
- **화면 UI(탭, 패널) 디자인/문구** → `src/ui/overlay.ts`, `src/ui/styles.ts`
- **캐릭터/아이콘 그림** → `src/game/art.ts` (이모지가 아니라 코드로 직접
  그린 손그림이에요)

수정한 뒤에는 `cafe-game` 폴더에서 `npx tsc --noEmit` 으로 타입 오류가 없는지
확인하면 안전합니다.
