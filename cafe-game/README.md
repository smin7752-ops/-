# 나의 작은 카페 (모바일 방치형 카페 경영 게임)

손님을 받고, 커피와 디저트를 팔아 돈을 벌고, 테이블과 직원과 메뉴를 늘려가는
모바일 웹 방치형(idle) 카페 경영 게임입니다. 지금 있는 AI 오피스 프로젝트와는
완전히 별개의 프로젝트로, 이 `cafe-game/` 폴더 안에서만 동작합니다.

## 실행하는 법

```bash
cd cafe-game
npm install
npm run dev
```

터미널에 뜨는 주소(`http://localhost:5173`)를 브라우저로 열면 됩니다.
휴대폰으로 확인하려면 같은 와이파이에 연결한 뒤, PC의 IP 주소로 접속하세요
(터미널에 `Network:` 로 시작하는 주소가 같이 나옵니다).

## 어떻게 노는 게임인가요

- 손님이 문으로 들어와 빈 테이블에 앉고, 원하는 메뉴를 말풍선으로 보여줍니다.
- 손님을 **탭(클릭)** 하면 주문을 받고 코인을 법니다.
- 너무 오래 기다리게 하면 손님이 화를 내고 나가버려요 (초록 막대가 인내심입니다).
- 화면 아래 **상점** 버튼에서 코인으로 다음을 살 수 있어요:
  - **테이블 추가** — 한 번에 더 많은 손님을 받을 수 있어요 (최대 8개)
  - **바리스타 직원** — 자동으로 손님을 응대해줘요. 게임을 꺼놔도 계속 일해서,
    다시 들어오면 그동안 번 돈을 몰아서 받습니다 (최대 8시간 분량)
  - **새 메뉴** — 더 비싼 메뉴를 팔 수 있게 돼요

진행 상황은 브라우저에 자동 저장됩니다(로그인 없이도 저장돼요).

없습니다 — "이 게임을 앱스토어에 낼 준비를 해줘" 라고 말씀해주시면 그때
Capacitor 설정을 추가해 드릴게요.

## 폴더 구조

```
cafe-game/
  src/
    game/       게임 규칙 (재화, 메뉴, 테이블/직원 가격, 저장/불러오기)
    scenes/     카페 화면 (Phaser 게임 엔진으로 그려지는 부분)
    ui/         코인 표시, 상점 창 (HTML/CSS로 그려지는 부분)
    main.ts     게임을 실제로 켜는 시작점
  index.html
```

## 손보고 싶을 때 어디를 고치면 되나요

- **메뉴 종류, 가격, 보상** → `src/game/config.ts`
- **테이블/직원 값 상승 곡선** → `src/game/config.ts`의 `tableCost`, `staffCost`
- **손님 인내심 시간, 손님 등장 속도** → `src/game/config.ts`
- **카페 이름, 화면 문구** → `src/scenes/CafeScene.ts`, `index.html`
- **상점 화면 디자인/문구** → `src/ui/overlay.ts`

지금은 캐릭터/아이템을 이모지(☕🍰🧃)로 표현하고 있어요. 나중에 직접 그린
그림이나 구매한 일러스트로 바꾸고 싶으면 말씀해주세요.
